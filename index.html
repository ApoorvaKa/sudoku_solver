    How to use

    • Type digits 1-9 into any empty cells.
    • Use the sample puzzle or start from a blank board.
    • Tap Solve to animate the backtracking search.
    • Tap Step to move one move at a time.

    Backtracking algorithm

    The solver uses depth-first search with constraint checking. At each empty cell, it picks a candidate value from 1–9, checks whether it violates Sudoku rules in the row, column, or 3x3 box, and only then places it. If that branch leads to a dead end, it backtracks and tries the next valid option. This continues until the board is full or no valid move remains.
